Step-by-Step Simplex Method

Use these general steps when solving a maximization problem using the simplex tableau.

01

Convert to standard form

Write the objective function and constraints in the required standard form. Add slack variables when appropriate.

02

Find the pivot column

For the usual maximization tableau, identify the most negative value in the bottom (Z) row.

03

Find the pivot row

Divide each eligible positive entry in the pivot column into its right-hand-side value. Choose the smallest non-negative ratio.

04

Perform pivot operations

Make the pivot entry equal to 1, then make the other entries in that column equal to 0.

05

Check optimality

Check the bottom row. If the tableau is not optimal yet, repeat the pivot process.

Reminder: The exact rules can differ depending on the tableau convention and whether the problem is a maximization or minimization problem. Follow your instructor's format.
